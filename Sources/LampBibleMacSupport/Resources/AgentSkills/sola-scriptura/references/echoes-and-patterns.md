# Echoes, patterns and principles

Read this when a reading rests on something no single verse states: an echo of
earlier scripture, a pattern recurring across contexts, a type, or a principle the
texts show in many particular cases.

Scripture is read by scripture, and the Lord and his apostles read it this way.
Jesus answered a question about the resurrection from God's words at the bush
(Matthew 22:31–32), and a question about the sabbath from David eating the
showbread and the priests' work in the temple (Matthew 12:3–7). Paul says Israel's
wilderness history was written for the admonition of later readers
(1 Corinthians 10:11). Reasoning of this kind is reading scripture, not importing
into it. Your job is to weigh how well the texts carry it. Do not dismiss a reading
because no verse states it outright, and do not wave it through because it is
edifying.

Like every passage, these illustrations are looked up before they are quoted or
characterised in an answer.

## What is being claimed

- **An echo:** a later passage takes up the words, images or situation of an
  earlier one without quoting it.
- **A pattern:** the same shape recurs in separate contexts — an act of God, a
  sequence of events, a way people respond — so that each instance can be read in
  the light of the others.
- **A principle:** a general truth the texts exhibit across particular cases
  rather than state in a sentence.
- **A type:** a person, event or institution read as prefiguring a later one.

All four are claims about connections in the text, so all four can be checked.
Hold them to the same standard: read both contexts in full, not only the lines
that match.

## The tests

Explicit statement remains the strongest evidence. A link that a writer of
scripture draws explicitly is that writer's claim: quote the text that draws it.
The remaining question is how far the drawn link reaches. A link that no writer
draws is at best inferred, and your work is to say how strongly it is supported.

Weigh these, and say what each one found:

1. **Distinctive shared language.** Look for the same uncommon word, phrase or
   construction. Check it in the original, through `TAHOT`/`TAGNT` or a translation
   tagged with Strong's, where English could create or hide the link. A word used
   hundreds of times links nothing on its own; a phrase found in only a few places
   links them. Say how you measured how rare it is (which search, which modules)
   and what the count covered.
2. **Several correspondences.** Look for more than one shared element, in the same
   relation or order. Count the correspondences, and count the differences you
   had to set aside to get them.
3. **The writer's use of the source.** A writer who quotes, names or plainly
   alludes to the earlier passage elsewhere is likelier to be echoing it here.
   This applies to the same writer first, and then to other writers drawing on
   the same passage.
4. **Recurrence.** The pattern appears in several writers or contexts that were
   not composed together. A pattern found inside one writer's vocabulary is the
   narrower evidence. See *Breadth of witness* in [verdicts.md](verdicts.md); its
   limits apply here too.
5. **Coherence.** The echo fits what the later passage is doing, and the earlier
   passage's sense carries over without being bent. An echo that makes the later
   passage say something its own argument does not need is weaker for it.
6. **Precedent.** Scripture explicitly draws links of the same kind elsewhere.
   A further instance of a kind of link scripture makes is more plausible than
   a kind it never makes. Precedent supports plausibility; it does not prove
   any particular instance.

Against the link:

- **The features are common.** If the same correspondences would tie the passage
  to many others, they identify none of them.
- **The match is selective.** It holds only once the differences are set aside, or
  only in one translation's wording.
- **It needs an outside key.** The correspondence works only through a symbol
  system, framework or background that scripture does not supply. That is an
  imported premise; see `inherited-vocabulary.md` and pattern 4 in
  `failure-patterns.md`.
- **It overturns plain statement.** An echo never sets aside what a text says
  plainly. Where a pattern reading and a statement conflict, report the conflict:
  the statement governs.

Two things are not tests. Commentators noticing an echo is agreement among
readers, not evidence. Treat it like a cross-reference link: a pointer to texts you
must still read. A reading heard all your life is not thereby drawn: ask which text
draws it, as a reader who had never heard it would.

## The grades

Give the grade with its reasons, so the writer can see what moved it.

| Grade | What it takes | Verdict for the link |
|---|---|---|
| **Drawn** | A writer of scripture makes the link. Quote the text that does. | Stated |
| **Strong** | Several correspondences that are distinctive and coherent in both contexts, usually with recurrence or the writer's own use of the source. For an echo, the distinctiveness is usually shared language. For a pattern or principle, it can be a specific shape (elements in the same order or relation) recurring in contexts not composed together, with no shared wording at all. | Inferred, strong |
| **Plausible** | Real support on more than one test, while a fair alternative remains, such as language shared only because it is a natural way to describe such an event. | Inferred, plausible |
| **Faint** | One distinctive resemblance — a rare word, a specific detail — with nothing else in support. Possible, not shown. | Inferred, faint |
| **Not shown** | Only features common enough to occur anyway, which identify no link in particular. Unsupported, with the scope. If the link needs an outside key, it is Imported instead. | Unsupported or Imported |

A link that overturns a plain statement is Contrary to that statement, whatever
its grade would otherwise be.

Grade the link and the claim built on it separately. A drawn or strong link can
still be pressed past what it shows: a type corresponds at the points the texts
make correspond, not at every point. Detail the earlier passage never had is the
writer's addition, and it is Inferred or Imported on its own terms.

Without the evidence a test needs, such as no original-language text for test 1,
call the grade provisional and say which test was not run. Do not keep searching
to manufacture a higher grade, or to rule one out.

## What a grade will bear

- **Drawn and strong** links can carry weight in an argument, including load,
  provided an undrawn one is presented as a reading: *the language of Exodus is
  hard to miss here* is a fair sentence about a strong echo; *this proves* is not.
- **A plausible** link illuminates and supports. When it is the only support for a
  load-bearing claim, the writing should say so.
- **A faint** link is worth offering as a suggestion and not worth building on.

## In an audit

The finding is never that a writer reasoned from a pattern. It is one of these:

- a confidence stated above the grade, such as a plausible echo presented as
  what the text teaches;
- a link that fails the tests;
- a conclusion that reaches past the link.

The remedy is usually the phrase any inference needs: *the language seems to
recall*, *I read this as echoing*, *the pattern suggests*. Where an echo is strong
and the writer has hedged it into nothing, saying that it is strong is a fair
service too.
