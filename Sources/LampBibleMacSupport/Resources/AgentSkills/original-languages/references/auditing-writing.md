# Auditing a writing's language claims

Read the whole piece and relevant supplied context before selecting claims. Use
`draft.md` in a writing workspace unless another is named. Never modify it as part
of the audit, and report in chat when no file output is authorised.

Inventory claims doing work through a word's meaning, tense/aspect/stem/voice/mood,
etymology, alleged original-language distinction or connection, translator bias,
frequency, word order or construction. A mere mention of Hebrew or Greek is not a
load-bearing claim.

For each claim, use the entrypoint's research procedure, reusing evidence and
batching compatible requests. Check [fallacies.md](fallacies.md). Use these
language verdicts, distinct from `sola-scriptura`'s scriptural verdicts:

| Verdict | Decision |
|---|---|
| Carried | The retrieved parsing, lexical evidence or counts show the claim; identify which |
| Permitted | The data allows this reading and alternatives; mark the judgement |
| Not carried | The checked data does not show the claimed conclusion; state its scope |
| Overreach | A form, etymology, gloss or frequency is made to settle more than it does; name the step |
| Translation-dependent | A rendering-specific observation is presented as a fact about the original |
| Unverifiable here | The necessary module, apparatus or analysis is unavailable or evidence incomplete |

An accurately attributed or already qualified claim is not an unmarked inference;
check any remaining error instead of asking for another hedge. Evidence in context
files is still checked. Missing data is not evidence against the writer.

For each consequential finding, quote the writing's sentence and the actual data,
name the module, explain the unsupported step, and give the smallest remedy. A
remedy may clarify an attribution or inference, correct a factual assertion, or
remove reliance on a claim. Do not apply it unless asked.

Order by what the piece rests on, consolidating repeated instances. A decorative
etymology is worth a line; a conclusion resting on a tense deserves an entry.
Include claims that check out without pretending they are findings. Close with
unverified claims and research limits. A non-language proof-text issue belongs
with `sola-scriptura`: either actually perform that check or name it as work not
done, rather than claiming an automatic handoff.
